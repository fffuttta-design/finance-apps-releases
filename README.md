# finance-apps-releases

FutaFinance / たくはるファイナンス / はるファイナンス の**配信専用**リポジトリです。
アプリの自動更新がここを見に来ます。**ソースコードは含みません**（ソースは非公開の `finance-apps`）。

| ファイル | 対象 |
|---|---|
| `futa-version.json` | FutaFinance（Android） |
| `futa-windows-version.json` | FutaFinance（Windowsネイティブ版・旧） |
| `takuharu-version.json` | たくはるファイナンス（Android） |
| `haru-version.json` | はるファイナンス（Android） |

APK は Releases に置きます。
